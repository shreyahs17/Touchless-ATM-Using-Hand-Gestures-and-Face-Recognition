# 🏧 Touchless ATM Using Hand Gestures and Face Recognition

## 📖 Overview

The **Touchless ATM Using Hand Gestures and Face Recognition** project is an innovative contactless banking solution designed to reduce physical interaction with ATM machines while improving security and user convenience.

The system authenticates users using **Face Recognition** and enables ATM operations through **Hand Gesture Recognition**, eliminating the need to touch the ATM keypad or screen.

This project was developed as a Bachelor of Engineering final-year academic project.

## 🔄 Project Workflow

1. User approaches the ATM.
2. Camera captures the user's face.
3. Face Recognition authenticates the user.
4. Hand Gesture Recognition detects user gestures.
5. User selects ATM operations.
6. LCD displays the selected operation.
7. Cash withdrawal or balance enquiry is completed.
